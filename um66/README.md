Astral Codex Theme (Homebrewery v3)

Files
- theme.css
  Self contained theme CSS. Uses embedded SVG data URIs for page graphics.
- astral_codex_theme.brew.md
  Upload to Homebrewery. It is tagged meta:Theme so it can be selected as a theme.
- astral_codex_demo.brew.md
  Upload to Homebrewery to see blocks used by the theme.
- assets/*.svg
  Source graphics used by the theme, included for editing.

Homebrewery notes
- Homebrewery v3 supports theme brews tagged meta:Theme and block syntax like {{frontCover}}, {{note}}, {{pageNumber,auto}}.
